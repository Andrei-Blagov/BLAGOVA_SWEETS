# Передача работы в Cursor при исчерпании лимита Plus

Использовать только если активная задача не завершена. Перед передачей сначала сохранить все безопасные изменения в ветке, обновить текущий commit SHA и зафиксировать результаты проверок.

## Что подготовить

1. Рабочая ветка и точный HEAD.
2. Одна конкретная незавершённая задача.
3. Уже выполненные изменения и изменённые файлы.
4. Ошибка или причина остановки.
5. Пройденные и непройденные проверки.
6. Ограничения из AGENTS.md и ссылки на PROJECT_STATE.md/ROADMAP.md.
7. Явный критерий завершения и команды проверки.
